# FinderSwipe（試作）のつかいかた

Finder が最前面のときだけ効く、スワイプ操作の常駐アプリです。

## 操作

- **2本指の横フリック**（速く・大きく）： 右へ → 戻る（⌘[）、左へ → 進む（⌘]）
- **3本指の下スワイプ**： 上の階層へ（⌘↑）
- **3本指の上スワイプ**： 選択中のフォルダやアプリを開く（⌘O）

## 準備

1. ビルドする： `sh ~/Documents/FinderSwipe/build.sh`
2. `FinderSwipe.app` を起動する
3. 初回はアクセシビリティ許可を求められます。システム設定 → プライバシーとセキュリティ → アクセシビリティ で FinderSwipe を許可して、アプリを再起動してください（キーを送るために必要です）

## ユニバーサルコントロールで使う場合

ユニバーサルコントロールは本物のキーボード入力しか相手側へ転送しないため、アプリが作ったキーは届きません（実機で確認済み）。そこで FinderSwipe 同士がネットワークで直接「合図」を送り合う形にしています。

1. **両方の Mac** に FinderSwipe を入れて起動する
2. **両方** でメニューの「相方モード（ネットワークで合図を送受信）」をオンにする
3. カーソルを相手側の画面に持っていき、相手側で Finder を開いた状態でスワイプする

- 触っている側で検知 → 合図がネットワークで相手側に届く → 相手側の FinderSwipe が、自分の Finder にキーを送ります
- 受け側は、自分の Finder が最前面のときだけ実行します
- 注意: 同じネットワーク内なら誰でも合図を送れてしまう試作仕様です。家庭内での利用を前提にしています

## Windows のエクスプローラーでも使う場合

合図の仕組みは OS に依存しないので、Windows 側に受け専用の小さなプログラムを置けば、エクスプローラーでも同じスワイプが使えます（`windows` フォルダ）。

1. Windows 側で `windows/build.bat` を実行すると `FinderSwipeReceiver.exe` ができます（Windows 標準のコンパイラを使うので追加インストール不要）
2. `FinderSwipeReceiver.exe` を起動する（初回はファイアウォールの許可を求められるので、プライベートネットワークで許可）
3. MacBook 側の FinderSwipe で「相方モード」をオンにする
4. Moonlight などで Windows を操作し、エクスプローラーを最前面にして、MacBook のトラックパッドでスワイプする

- Windows 側のキー対応: 戻る = Alt+←、進む = Alt+→、上の階層 = Alt+↑、開く = Enter
- エクスプローラーが最前面のときだけ実行します
- Chrome などの Chromium 系ブラウザが最前面のときは、2本指フリックで履歴の戻る／進むが効きます（Alt+←／→。「上の階層」「開く」は対象外）
- 相方モードがオンのときは、Moonlight が最前面でもキー直送ではなく合図を送ります（Windows のように受け側でキー変換が必要な相手向け）

## カーソル共有（試作・3台まで数珠つなぎ）

Deskflow のようなカーソル共有の試作です。Mac 2台＋Windows 1台のような構成で、カーソルが端を越えて隣のマシンへ渡っていきます。

### 準備（全マシン共通）

1. 全マシンで FinderSwipe（Windows は FinderSwipeReceiver.exe）を起動する
2. Mac はメニューの「カーソル共有（端で相手に渡す）」をオンにする

### レイアウト設定（Mac）

メニューの「レイアウト（相方の配置）」を開くと、起動中の相方が名前で一覧できます。各マシンで、**隣のマシンをその方向に置く**設定をします。

例（左から Mac mini / MacBook / Windows の並び）:

- MacBook: Mac mini を「左」、Windows を「右」に置く
- Mac mini: MacBook を「右」に置く

### レイアウト設定（Windows）

`FinderSwipePeer.ini`（exe と同じフォルダ、初回起動で自動生成）を書き換えて再起動します。起動画面に自分の ID が出るので、それを Mac 側のレイアウトで選べるように、まず Windows 側で相手の ID を書きます。

- MacBook の ID は、MacBook の「レイアウト」メニュー先頭に表示されます
- 例: `left=<MacBook の ID>`（Windows が右端なら左隣だけ書けば OK）

### 使い方

- カーソルを隣のいる方向の端にぶつけると、操作が隣に移ります（隣の向かい合う端に、同じ比率の位置でカーソルが出ます）
- カーソル共有で相手を操作している間は、スワイプ操作（戻る／進む／上の階層／開く）も相手に送られます
- 隣でもさらにその先の端を越えると、次のマシンへ中継されます
- 来た側の端を越えると、1つ手前に戻ります
- **詰まったら ⌘Esc**： どのマシンで押しても全体をリセットできます（Esc 単体は普通のキーとして扱います）
- 送れるのはマウスの移動・クリック・スクロールと、基本的なキー入力です

割り切り（試作の範囲）:

- 複数ディスプレイは、全体の外形（いちばん外側の枠）で判定する近似です。ディスプレイ同士の段差部分では位置がずれることがあります
- 日本語入力（IME）の変換中の文字は正しく渡らないことがあります。英語入力での確認がおすすめです
- 起点になれるのは Mac だけです（Windows のマウスから操作を始めることはできません）
- Mac 側では「入力監視」の許可を求められる場合があります（求められたら許可してください）

## リモート操作で使う場合（Sunshine / Moonlight など）

指の動きは「触っている側のマシン」でしか読めません。MacBook から Mac mini を操作している場合は、**MacBook 側にも FinderSwipe を入れてください**。

- MacBook 側でメニューの「リモート操作モード（Moonlight 使用時も有効）」をオンにする
- Moonlight が最前面のときにスワイプすると、⌘[ などのキーが Moonlight 経由で相手側に送られます
- 操作される側（Mac mini）の FinderSwipe は、そのマシンのトラックパッドを直接使うとき用です。両方入っていても構いません

## メニュー

メニューバーに指3本のアイコンが出ます。

- 「有効」： オン／オフの切り替え
- 「最後の検出」： 直近に反応したスワイプの内容（動作確認用）

## 既知のこと（試作の割り切り）

- 2本指の横フリックは、スクロールと見分けるため「0.6秒以内に大きく動いたもの」だけ拾います
- 指の読み取りには macOS 内部の仕組み（MultitouchSupport）を使っています。OS の更新で動かなくなる可能性があります
- 反応が悪い・誤爆する場合は、しきい値の調整が要ります

## レイアウトの変え方（手順）

レイアウトは「そのマシンから見た隣の位置」で、マシンごとに保存されます。変えるときは1台ずつ設定します。

1. 設定したいマシンで、アプリのメニュー「レイアウト（相方の配置）」を開く
2. 発見されている相手ごとに「右に置く／左に置く／上に置く／下に置く」を選ぶ
3. 隣り合う同士では互いに逆向きに設定する（例: MacBook の右に mini を置いたら、mini の左には MacBook を置く）
4. Windows は相手を自動で覚えるので、この設定は要りません

カーソル共有で相手の画面を操作しているときは、そのまま相手側のメニューを開いて設定できます。起点に戻りたいときは ⌘Esc でセッションをリセットしてください。
